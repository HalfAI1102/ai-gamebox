# 猜人物（guesswho）

经典的“20 个问题”。每一轮用户在网页上选模式：

- **ai_thinks**：你想一个人物，用户提问来猜。
- **human_thinks**：用户想一个人物，你提问来猜。

## 你来想（ai_thinks）

1. 想一个**大多数人都认识**的人物或角色（明星、历史人物、动漫/电影/游戏角色、神话人物都行），别太冷门。
2. `game.py think --secret 孙悟空 --category 神话人物`。分类是给用户的范围提示，可以写宽一点（比如“虚构角色”）。答案存在服务器里，网页看不到。
3. 用户每提一个问题，你都会在 `wait` 里收到，用 `game.py answer yes|no|partly|unknown|irrelevant` 回答，可以加一句很短的补充（不能泄露答案）。
   - `unknown`：这个问题你也不确定答案。
   - 用户一次问了好几件事，就按最关键的那个回答，并用 `say` 说明。
4. 用户在“我猜是”里猜。名字完全一样服务器会自动判对；如果是别名或少了几个字但明显指同一个人（如“孙大圣”“悟空”），用 `game.py accept` 判对。
5. 用户最多问 20 个问题。问完还没猜中，或者用户放弃，就 `game.py reveal`。

## 用户来想（human_thinks）

1. 用户想好后你会收到“对方想好了一个人物（分类：…）”。
2. 用 `game.py ask "问题"` 提问，每次一个，等用户点“是 / 不是 / 部分是 / 不知道”回答（会在 `wait` 里收到）。
3. 先问大范围（真实还是虚构？男性？还活着吗？中国的？），像二分查找一样缩小范围。
4. 有把握了就 `game.py guess 人物名`。名字对上服务器会直接判对；对不上会变成“是「xx」吗？”让用户确认。
5. 尽量在 20 个问题以内猜中，猜之前可以 `say` 一句你的推理，增加乐趣。
