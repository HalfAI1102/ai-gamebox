# 你画我猜（drawguess）

每一轮由用户在网页上选模式：

- **ai_draws**：你出题作画，用户猜。
- **human_draws**：用户作画，你看图猜。

## 你来画（ai_draws）

1. 收到“对方选择：你画对方猜”后，想一个**简单、具体、好画**的词（动物、水果、日常物品），2–4 个字。
2. 写一个 JSON 文件（或通过标准输入传入）描述笔画，然后：
   `game.py draw --word 苹果 --paths /tmp/apple.json`
   或 `game.py draw --word 苹果 --paths - < /tmp/apple.json`
3. 网页会一笔一笔动画播放你的画。词保存在服务器里，用户看不到。
4. 用户在网页里猜，你会在 `wait` 里收到“对方猜：xx → 不对 / 猜对了”。猜错时可以用 `say` 逗一逗、鼓励；连续猜错 3 次左右可以 `game.py hint "提示"` 或 `game.py add-paths --paths ...` 补几笔。
5. 猜对了就 `say` 庆祝；用户放弃会自动公布答案。你也可以 `game.py reveal` 主动公布。

### 笔画格式

画布是 **400 × 300**（左上角是 0,0）。每一笔是一条 SVG path：

```json
[
  {"d": "M200 80 C150 80 120 130 130 180 C140 240 260 240 270 180 C280 130 250 80 200 80 Z", "color": "#e85d5d", "width": 5, "fill": "#ffd0c2"},
  {"d": "M200 80 Q205 55 220 45", "color": "#8b5e3c", "width": 5},
  {"d": "M210 62 Q235 45 250 60 Q230 72 210 62 Z", "color": "#5fc39e", "width": 3, "fill": "#9fe0c6"}
]
```

- `d`：SVG 路径（M 移动、L 直线、Q/C 曲线、A 圆弧、Z 闭合）。
- `color`：线条颜色；`width`：线宽 1–20；`fill`：填充色，不填就是空心。
- 笔画按顺序播放，像真人一样先画大轮廓再画细节，5–15 笔为宜。
- 画成可爱的简笔画风格就好，**不要写字**，不要画出答案文字。
- 可选配色：`#5b4660` 深紫、`#e85d5d` 红、`#ff9a5c` 橙、`#f2c230` 黄、`#5fc39e` 绿、`#5aa9e6` 蓝、`#a68cff` 紫、`#8b5e3c` 棕。

## 用户来画（human_draws）

1. 用户在网页上选词、作画，点“给你看”后，`wait` 会返回一张图片的本地路径和词的字数。
2. **打开这张图片看**（用你读取图片的能力），然后 `game.py guess 词`。命令会告诉你猜对没有。
3. 每次猜之前可以 `say` 一句你的思考，比如“圆圆的、有叶子……”。没猜中可以再猜，最多连猜 3 次，之后 `say` 请用户补几笔，等下一张图。
4. 如果你没法看图片，诚实地 `say` 告诉用户“我现在看不到图片，换你猜我画吧”，并建议用户点“再让我画”。
